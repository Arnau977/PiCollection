# Keyboard shortcuts

Every button with a shortcut shows it in its tooltip. While you're typing in
a field, single-key shortcuts are ignored, and the first `Esc` just leaves
the field.

| Where | Keys | Does |
|---|---|---|
| Anywhere | `Ctrl+B` | Toggle NSFW blur |
| Media page | `←` / `→` | Previous / next item |
| Media page | `E` | Edit |
| Media page, edit form | `Ctrl+F` | [Find a tag](viewing-media.md#finding-a-tag) on this item (`Esc` closes it) |
| Edit form | `Ctrl+S` | Save |
| Edit form | `Ctrl+Shift+S` | Save & mark resolved (pending items) |
| Edit form | `Ctrl+Shift+A` | Suggest tags locally (local AI) |
| Edit form | `Esc` | Leave the form (asks first if there are unsaved changes) |
| Batch import, pending queue | `Alt+←` / `Alt+→` | Previous / next file |
| Full-size viewer, comparison | `+` / `-` / `0` | Zoom in / out / fit |
| Full-size viewer, comparison | `Esc` | Close |
| Video player | `Space` / `K` | Play / pause |
| Video player (keyboard focus in its controls, or full screen) | `←` / `→` | Back / forward 5 seconds |
| Video player (keyboard focus in its controls, or full screen) | `↑` / `↓` | Volume up / down |
| Video player, paused | `,` / `.` | Previous / next frame |
| Video player | `[` / `]` | Set the looped section's start / end |
| Video player | `Shift+L` | Clear the looped section |
| Video player | `L` | Loop on / off |
| Video player | `M` | Mute |
| Video player | `F` | Full screen |
